# PPT 演示文稿生成（ppt-deck）

## 适用场景

用户要求"做 PPT""生成演示文稿""整理大纲"时激活。

## 工作流

1. 明确主题与受众（对内/对外、正式/轻松）。
2. 生成大纲：标题、章节、每页要点（无 LLM 时按骨架模板填充）。
3. 选择版式：从 4 类版式模板中为每页挑选组合（封面/目录/内容/结尾）。
4. 输出 deck.md：按版式模板渲染 Markdown 结构。
5. 可选生成 HTML 预览：把 deck.md 转成单文件 HTML。

## 版式模板（4 类）

| 版式 | 用途 | Markdown 结构 |
|------|------|--------------|
| 封面 | 首页 | # 标题 + ## 副标题 + 作者/日期 |
| 目录 | 总览 | 有序列表列章节 |
| 内容 | 正文 | 每页 ## 小节 + 要点 + 数据表格 |
| 结尾 | 收束 | 总结 + 行动项 + 致谢 |

### 封面模板

```markdown
# <大标题>
## <副标题>
演讲人：<姓名> | <日期>
```

### 内容页模板

```markdown
## <小节标题>
- 要点 1（一句话结论）
- 要点 2（支撑数据）
| 指标 | 数值 |
|------|------|
```

## 增强选项

- Agent 有 LLM 时：用 LLM 充实文案、提炼金句、生成演讲备注。
- 无 LLM 时：直接输出骨架，用户自行补文案。

## 输出格式

```markdown
## deck.md 结构
1. 封面页（版式：封面）
2. 目录页（版式：目录）
3. 内容页 ×N（版式：内容）
4. 结尾页（版式：结尾）
```

## selfcheck

- 骨架生成不依赖任何外部服务。
- HTML 预览仅本地渲染，不上传任何平台。
- 运行 spectre 扫描应 clean。
