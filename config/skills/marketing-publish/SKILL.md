# 营销分发（marketing-publish）

## 适用场景

用户要求"写小红书文案""发公众号推文""做营销推广"时激活。

## 安全边界（必读）

- 文案生成（草稿）是本地操作，可直接执行。
- 真实发布为高危写操作：
  - 需 VAP_ALLOW_WRITE_PUBLISH=1 且人工审批通过。
  - 当前实现仅 Mock：生成分发清单，绝不真实调用公众号/小红书/微博/抖音接口。
- 未获批时流程止步于「分发清单」，不执行任何真实发布。

## 工作流

1. 明确平台与目标（拉新/促活/转化）与品牌基调。
2. 按平台风格模板生成文案草稿。
3. 生成分发清单：平台、时间、账号、内容版本。
4. 提交发布审批（含文案全文与平台清单）。
5. 获批后执行 Mock 发布，记录模拟回执。

## 平台风格模板

| 平台 | 风格 | 要点 |
|------|------|------|
| 公众号 | 深度长文 | 标题克制、段落化、结尾行动引导 |
| 小红书 | 种草清单 | 轻量 emoji、分段小标题、真实体验口吻 |
| 微博 | 短平快 | 140 字内、话题标签、时效性 |
| 抖音 | 口播脚本 | 前 3 秒钩子、短句、动作提示 |

## 输出格式

```markdown
## 文案草稿
<平台>：<正文>

## 分发清单
| 平台 | 发布时间 | 账号 | 版本 |
|------|---------|------|------|

## 审批状态
<待审批 / 已批准 / 已拒绝>

## 发布回执（Mock）
<模拟回执文本>
```

## selfcheck

- 无 VAP_ALLOW_WRITE_PUBLISH=1 与人工审批，绝不产生真实发布动作。
- 所有分发均为 Mock，不触任何平台接口。
- 运行 spectre 扫描应 clean。
