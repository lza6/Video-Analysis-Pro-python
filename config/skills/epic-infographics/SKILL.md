# 视频分析信息图生成

## 适用场景

当用户要求"做成一张信息图""把分析结果可视化""生成一图流""做个图表海报"时激活。

## 工作流

1. **明确 brief**：先钉死三件事——受众（给谁看）、目标（传达什么/说服什么）、画布（社交方图 1080×1080 / 竖屏 1080×1920 / 宽幅 1920×1080 / A4 打印）。用户没说就给 2-3 个故事角度候选让其选：每个角度=一句工作标题+一个主数字+一句话回答"读者该记住什么"。
2. **收集数据（不编造）**：从已有分析产出取数——Phase 2 总结报告、`transcript.segments`（时长/语速/语言分布）、`run_ocr` 的画面文字、`get_frame_details` 的逐帧 caption、画质趋势图数据。数值只能来自这些产出或用户输入，推算值必须标注"示意"。
3. **定视觉隐喻**：列 2-3 个主题唤起的实物（咖啡杯、阶梯、聚光灯…），选一个能"承载数据"的（杯子的液面高度=占比、阶梯台阶=步骤数）。这是整张图的场景主体，避免"卡片网格+平背景"的模板感。封面文字后仍能认出主题才算合格。
4. **挑数据形态**：一个主角元素（大数字/主图表/主图形）+ 2-4 个不同类型的辅助元素（进度条/时间线/对比/图标阵列），禁止三个同型图表并列。柱状比、环形角、面积全部按数值计算，不许目测。
5. **构建单文件 HTML**：内联 CSS 变量做设计令牌、图表用内联 SVG、无 JS 框架、无外部资源（字体除外）。**需外部工具/后续版本**：主项目暂无渲染脚本，手动渲染用 Playwright 截图——

   ```bash
   npx playwright screenshot --viewport-size=1080,1080 --wait-for-timeout=1500 infographic.html infographic.png
   ```

6. **自审（必做一轮）**：读回 PNG 检查——文字有无溢出/裁切/碰撞；主角元素是否一眼可见（眯眼测试只有一个焦点）；图表比例是否与数值一致；对比度是否可读；盖住文字能否认出主题；是否像"仪表盘模板"（是则重排而非修补）。修完重渲染再交付。

## 输出格式

- `infographic.html`（单文件源码）+ `infographic.png`（渲染图）
- 数据来源清单：每个数字后注明取自哪份分析产出
- 自审清单勾选结果
