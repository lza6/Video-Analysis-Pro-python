3. 关键修复(收口阶段发现的真问题)

P0 修复(阻塞):
  • 桌面版闪退根因:runtime-controller.js 原用 python src/web/serve.py(脚本直跑),serve.py 内部 from .config import get_settings 相对导入 → ImportError: attempted relative import with no known parent package。改用 python -m src.web.serve --no-browser(包模块入口,与 launcher.py 一致)。实测端口探测 8001 成功。
  • electron 二进制下载失败:npm install 时 electron postinstall 从 github.com 下载 ECONNRESET。配 ELECTRON_MIRROR=https://registry.npmmirror.com/-/binary/electron/ 走国内镜像,装上 electron.exe(188MB)。
  • 端口被占闪退:serve.py 已自动跳端口(8000→8001),electron 的 stdout 探测需 5s 兜底走 health 轮询(已实现),实测 8000 被占→跳 8001→窗口 loadURL 成功。
  • logo 旧构建残留:webapp/out/logo.svg 是旧构建(已删 out,下次启动 serve.py 自动 rebuild)。
  • Remote router async bug:RemoteManager.prepare/start/stop/status 全是 async coroutine,原写 asyncio.to_thread(mgr.start,...) 当同步函数调 → coroutine never awaited + PydanticSerializationError。改直接 await + TunnelStatus 是 frozen dataclass 非 pydantic,手动转 dict。
  • IM router IMMessage 构造:原手建 IMMessage 缺 msg_id 必填。改用 mailbox.put_inbound(关键字参,内部自动生成 msg_id)。

5. 剩余风险与边界(诚实)

  • IM 网关真实凭据:三 adapter 全 Mock,真实微信/TG/Discord token 未配置(付费 API 预算 0)。Mock 闭环全验证,真实化需用户授权凭据后替换 adapter。
  • 远程访问真实 tunnel:Tailscale/Cloudflared 未真实连(Mock 返回 mock-node.tailnet.ts.net)。契约对齐 Minke,真实化需装 tailscale/cloudflared CLI + 凭据。
  • Agent 框架 LLM 真实接入:ReactLoopAgent 用 MockLLMClient 测试通过,生产 ProviderRouterClient(包 ProviderRouter 成 LLMClient stream)未写(避免改 provider_router.py 边界)。接真 NVIDIA 需主控在 loop.py 旁加 adapter.py。
  • test_skills_match 1 failed:既有缺陷(skill 路由匹配),非本次改动引入,标 P2 不阻塞 v9。
  • GPU 进程报错:electron 在无显示/模拟环境跑时 GPU process exit_code=143(正常,headless 环境无 GPU)。真实双击有 GPU 不报。
  • electron-builder 真实打包:配置齐全(electron-builder.yml),但未真实跑 npm run build:win(需下载 nsis + 7z,耗时数分钟,且 venv 体积大数 GB,建议用 PyInstaller 打 serve.py 单 exe 再 electron 包)。
  • GitHub Release:未推送(gh CLI 不可用 + 无凭据)。需用户授权 git push origin main --tags 后创建 Release。
