📌 上下文：这次变更为什么发生

你的目标是把 TingFeng Hermes（视频分析 + 通用全能 Agent 桌面平台）从 v10.1.0 推进到 v10.2.0：让 Agent 主线真正闭环、把后端 router 覆盖率从 ~68% 冲上 80% 门禁、修复真实调用方会踩的 bug、并完成可交付的 E2E/验收/审计。

核心诉求拆成三件事：① Agent 智能闭环（ReactLoopAgent 接入、tools 透传、OpenAI 兼容工具 schema）、② 覆盖率冲刺（8 个低覆盖 router 补真实测试）、③ 收尾可交付（版本五同步、模型文件 gitignore、工作流状态文档）。

🎯 直觉：怎么理解这次改动

整个改动可以浓缩成一个心智模型："Agent 要能真正干活，且我们能证明它在干活。"

  • 闭环：旧版 react 路径的 LLM 客户端是"纸面引用"——docstring 提到生产用 ProviderRouterClient 但从未实现；tools 也不透传，LLM 根本调不了工具。现在补齐了实现并让 tools 真实进入 payload。
  • 兼容：NVIDIA 端点要求 OpenAI 规范的 {type:"function", function:{...}} 格式，项目原来是私有平面格式导致真实调用 400。我们按真实 API 复现后修到 200。
  • 可验证：8 个 router 从 20%~51% 冲到 ≥89%，每个测试文件都按"真实 TestClient + monkeypatch 隔离外部依赖 + 守付费红线"写。
