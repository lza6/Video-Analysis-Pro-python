## 使用约定

1. **每次迭代完成后**：更新 `下一步改进指南.md` 中被核销的批次状态，把新发现追加进去，保持它始终是"最新的下一步"；旧版指南移入 `archive/` 前先核对新版已包含其全部未完成批次。
2. **执行前**：先读 `下一步改进指南.md` 的「第零章 给执行 AI 的作业契约」与「第一章 现状核查」，再读 `CLAUDE.md` 的项目约定。
3. **不要在此目录放源码或构建产物**。
4. 本目录（含 archive/）为规划文档，默认不进入功能代码提交；如需入库单独拆 docs commit。
